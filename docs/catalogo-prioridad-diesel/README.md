# Paquete de catálogo diésel para Victor Services

Contenido preparado el 12 de agosto de 2026:

- 15 referencias prioritarias confirmadas: 8 filtros y 7 componentes de suspensión.
- 11 fotografías exactas procesadas para web, cada una con EXIF y sidecar JSON.
- 4 referencias Gabriel conservadas como pendientes porque las páginas encontradas mostraban una imagen genérica.
- Manifest JSON listo para consumo por la aplicación.
- Inventario Excel con referencias, fichas, precios, brechas, fuentes y diccionario de metadata.
- Prompt maestro para que Antigravity implemente la colección sin inferir datos.

Los precios son sugeridos para publicación y deben validarse contra costo real, IVA, inventario, transporte y margen. La compatibilidad debe confirmarse por VIN, código de motor, año y tracción.

Las imágenes siguen sujetas a los derechos de sus fabricantes o distribuidores. La metadata conserva la fuente y una alerta para revisar la autorización de uso comercial.
