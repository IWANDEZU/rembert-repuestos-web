# Borradores de fotos candidatas GTI

Generado desde `docs/catalogos-gti/gti-source-candidates-direct.json`.

- Candidatas con coincidencia documental: **10**.
- Estado de estos archivos: **no autorizados para publicar**.
- Para usar un lote, validar la fotografía, cambiar `usage_authorized` a `true`, indicar `source_type` y cambiar `source_image_clean` a `true`. Después ejecutar `npm run catalog:image-update -- <lote.json> --apply`.

El importador rechaza los borradores mientras persistan los valores de bloqueo.
