## Imágenes

Las 13 imágenes en `public/catalogo-ads/` son recreaciones de catálogo generadas para REMBERT, no fotografías oficiales ni evidencia de existencia. Conservan la apariencia del repuesto, un empaque ADS claramente rotulado y el medallón REMBERT. Se exportaron a WebP cuadrado, máximo 1400×1400 y entre aproximadamente 54 y 114 KB.

Modo de generación: `imagegen` con referencias locales del anuncio ADS y del medallón REMBERT. Cada referencia se generó de forma individual; el prompt exigió producto completo, fondo de estudio, margen para `object-fit: contain`, referencia legible, ausencia de precios/certificaciones inventadas y sello REMBERT en la esquina inferior derecha. SK-022 recibió una edición adicional para retirar un grabado incorrecto del producto.

## Regla comercial

No vender por semejanza fotográfica. Confirmar VIN, referencia OE/fabricante, posición, lado, medidas, estrías, roscas, transmisión y ABS según corresponda. Las cifras de mercado son solo observaciones externas y no sustituyen el precio ni la existencia de REMBERT.
